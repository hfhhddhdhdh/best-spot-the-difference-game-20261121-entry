Spot the Difference — The Curio Garden: a complete, original spot-the-difference game with five hand-drawn scenes, seven hidden differences per scene, a timer, score and combos, hints, keyboard play, and synthesized sounds — all static files, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play. Or open `game/index.html` directly from the files (use the server for the full experience).
